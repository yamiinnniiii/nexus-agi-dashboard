# ⚡ NEXUS AGI Dashboard

A futuristic personal command center built with React, TypeScript & Vite — featuring cognitive telemetry, task management, project portfolios, AI intelligence feeds, and ambient soundscapes.

## ✨ Features

- 🧠 **Cognitive Matrix** — Focus score, Pomodoro timer, circadian rhythm chart & life telemetry
- 📋 **Task Board** — Priority-weighted tasks with category filters & confetti celebrations
- 📝 **Notepad & Scratchpad** — Rich note-taking with categories and quick capture
- 📁 **Project Manager** — Full project portfolio with tags, progress tracking & details
- 🧬 **Personal Memory** — Persistent memory bank for facts, preferences & context
- 🎯 **Goal Tracker** — Weekly goals with visual progress bars
- 📡 **AGI Intelligence Feed** — Curated AI/Tech/Strategy news synthesis
- 🎵 **Ambient Sound Engine** — Web Audio binaural alpha waves & white noise for deep focus
- ⚡ **Quick Launcher** — Cmd+K command palette for instant navigation
- 🌙 **Focus Mode** — Distraction-free single-column view

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Installation

```bash
git clone https://github.com/yamiinnniiii/nexus-agi-dashboard.git
cd nexus-agi-dashboard
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
